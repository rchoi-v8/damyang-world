# 담양 월드 · 풍경 속으로 로그인!

학생용 담양 답사 웹페이지입니다. 픽셀 느낌의 창, 파스텔 색상, 대나무 길잡이 캐릭터를 사용했습니다. 별도 설치나 빌드 없이 GitHub Pages에 배포할 수 있습니다.

이 폴더의 **내용물 전체**를 저장소 루트에 업로드하세요. `index.html`, `assets`, `images`의 상대 위치와 파일명 대소문자를 유지하세요. 경로는 모두 `./assets/...`, `./images/...` 형식입니다. 저장소 이름이 붙는 GitHub Pages 프로젝트 주소에서도 작동합니다. ZIP을 업로드할 때에는 먼저 압축을 풀어 내용물을 올리세요.

저장소의 GitHub Pages 설정에서 파일을 올린 브랜치의 루트(`/`)를 배포 대상으로 선택하고, 배포 후 표시되는 사이트 주소를 학생들에게 공유하세요.

## 이번 구성

원본 PDF 1–9쪽을 직접 확인해 담양군의 지리·인구·행정구역·지명 유래와 선사시대부터 근현대까지의 역사를 추가했습니다. 행정구역 지도(3쪽)와 조선 후기 지도(7쪽)를 포함하며, 인구 등은 자료집 수록값으로 표시합니다. 지도에 남아 있는 옛 명칭 남면은 가사문학면 개칭 설명과 연결했습니다.

8개 방문지별로 기본 정보, 사진, 역사와 배경 설명, 현장 관찰 포인트, 이해 도식, 용어 풀이, 다른 장소와의 연결을 모았습니다. 석당간·오층석탑은 두 사진을 나란히 비교합니다.

마지막 화면에는 닉네임으로 작성하는 공용 댓글이 있습니다. 댓글은 Supabase의 담양 전용 프로젝트에 저장되며 모든 방문자가 읽을 수 있습니다. 브라우저에는 연속 등록을 줄이기 위한 임의 식별자만 저장합니다. 닉네임은 20자, 댓글은 1,000자까지이며 동일 브라우저 기준 30초에 한 번, 하루 20개까지 작성할 수 있습니다. 이 식별자는 로그인이나 본인 확인 기능이 아닙니다. 댓글을 표시하는 동안 30초 간격으로 새 글을 확인하며 새로고침 버튼으로도 불러올 수 있습니다.

휴대폰 화면(760px 이하)에서는 한 페이지씩 읽습니다. 왼쪽으로 밀면 다음 장소로, 오른쪽으로 밀면 이전 장소로 이동하며, 각 페이지의 긴 본문은 세로로 스크롤합니다. 하단 이전·다음 버튼과 페이지 선택 목록으로도 이동할 수 있습니다. 표를 가로로 스크롤하거나 사진 확대·링크를 누르는 동작은 장소 전환에서 제외합니다. PC에서는 기존의 세로 배치를 유지합니다.

장소 이동과 전체 본문은 JavaScript 없이도 기존 세로 배치로 읽을 수 있습니다. JavaScript는 모바일 페이지 이동, 사진 확대 및 PC의 현재 장소 메뉴 표시에 사용합니다. 사진 확대는 닫기 버튼 또는 Esc로 닫을 수 있습니다. 외부 폰트·라이브러리 없이 기본 글꼴과 CSS/SVG 그림으로 구성했습니다. 지도·출처 링크와 최초 웹 접속에는 인터넷이 필요합니다. 오프라인 캐시는 제공하지 않습니다.

## 내용과 출처

부산대학교박물관 『담양 자료집』의 해설, 장소 사진 9장과 지도 2장을 바탕으로 재구성했습니다. 담양군 소개·역사는 작업 폴더의 원본 PDF를 직접 확인했습니다. 장소별 기본 해설은 기존 노트의 요약을 이어받았습니다. 페이지에 표시한 쪽수는 기존 요약의 인쇄 쪽수이며 PDF 페이지는 +2입니다.

입문용 보충 설명을 추가했으며, 기묘사화·소쇄원·성산별곡 등의 외부 참고 링크를 각 장소 아래에 표시했습니다. 비교와 해석 문장은 학습을 위한 설명입니다. 자료집 발췌 사진의 권리는 원권리자에게 있습니다.

공식 일정은 페이지의 부산대학교박물관 공지 링크를 확인하세요. 실제 이동·공연·보존처리 상황은 인솔 안내를 따릅니다.

내용 확인 과정에서 이전 노트의 관방제림 황종림 식재 연도(1794)를 국가유산포털에 따라 1854년으로 바로잡았습니다.
